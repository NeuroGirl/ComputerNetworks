# Мониторинг и логирование Nextcloud

## О проекте

Лабораторная работа посвящена развёртыванию системы мониторинга и логирования Nextcloud с использованием **Docker Compose, Zabbix, Promtail, Loki и Grafana**.

В ходе работы настроены проверка доступности сервиса, централизованный сбор логов и визуализация данных в Grafana.

## Содержимое репозитория

- `containers_status.txt` — информация о состоянии запущенных Docker-контейнеров.
- `docker-compose.yml` — конфигурация развёртывания всех сервисов через Docker Compose.
- `nextcloud_log.txt` — пример журнала событий и ошибок Nextcloud.
- `promtail_config.yml` — настройки сбора логов Nextcloud и их передачи в Loki.
- `template.yml` — шаблон мониторинга Zabbix с элементами данных для проверки состояния Nextcloud.
- `Мониторинг и логирование Nextcloud.pdf` — отчёт по лабораторной работе с описанием настройки, скриншотами и результатами.

## Результаты

В Grafana созданы три дашборда:

1. **HEALTH RADAR** — мониторинг текущего состояния Nextcloud.
2. **BLACK BOX** — просмотр и фильтрация логов.
3. **MISSION CONTROL** — комплексная визуализация состояния сервиса и активности событий.

## Вывод

Развёрнута система мониторинга и логирования Nextcloud, позволяющая контролировать доступность приложения, анализировать ошибки и отслеживать события через Grafana.
